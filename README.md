# Spin — The Active Inference Pocket Lab

A mobile-first browser lab for learning active inference through switchable
Pulse, Vision, and Core streams. Its modules follow the chapters in Parr,
Pezzulo, and Friston's *Active Inference*.

- [Open the live lab](https://active-inference-pocket-lab.netlify.app)
- [Start the lab locally and explore the docs](docs/README.md)
